How it works

Four steps. One final settlement.

AxLink connects institution custody vaults directly. No correspondent chains, no batch windows, no manual reconciliation.

01
🏛️
Institution onboards
Regulated institution completes KYB and sanctions screening. A Fireblocks custody vault is provisioned exclusively for them.
›
02
📥
Fund the vault
Deposit USDT or USDC to the institution's on-chain vault address. Balances are credited on Solana finality — typically under 5 seconds.
›
03
⚡
Initiate settlement
Call POST /v1/transfers with counterparty and amount. AxLink validates policy, journals the reservation, and executes.
›
04
✅
On-chain finality
Solana confirms the transaction. AxLink verifies the txHash independently, marks the transfer SETTLED, and fires webhooks to both parties.

Technology

Every settlement is independently proven.

AxLink does not trust Fireblocks' confirmation. It reads the Solana RPC directly and verifies finality before crediting any account.

🔑

MPC Custody via Fireblocks

Every institution vault is a Fireblocks MPC-CMP vault. No single key, no hardware risk. Transaction policy enforced before any signature is issued.

⛓️

Solana Finality Proof

Settlements are proven finalized on Solana — not just broadcast. AxLink polls a dedicated RPC node until the signature status is finalized.

📒

Double-Entry Ledger

Every posting is a balanced journal entry. Σ debits always equals Σ credits. Trial balance and reconciliation run continuously — zero suspense is the daily target.

🔄

Crash-Recoverable Settlement

The settlement plan is written before any external call. A resume worker drives stalled legs forward — customer money is never silently stuck.

🛡️

Idempotent Transfers

Pass an Idempotency-Key. A retried request returns the original result — the same transfer is never paid twice, even across network failures.

🔔

Signed Webhooks

Every event is delivered to your registered endpoint with an HMAC signature. Delivery follows a 1m/5m/30m/2h/12h retry schedule with full delivery history.

Infrastructure

What runs under the hood.

AxLink is built on a provider-agnostic architecture. Every external dependency — Fireblocks, Solana, screening — sits behind a port. Swapping one adapter never touches the settlement core.

No token issuance
AxLink moves existing public stablecoins. Nothing is minted, nothing is lent.
Segregated vaults
Each institution's assets are in a named, dedicated Fireblocks vault — never commingled.
On-chain positions published
Every vault address is public. Total network reserves are verifiable on Solana Explorer at any time.
